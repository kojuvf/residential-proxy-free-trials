## 存在两种不同的“免费试用”，选择错误的类型会浪费你一周的时间

## 陷阱：你的“1,000,000 credits”可能只能买 40,000 个页面

这是大多数评测跳过、但对你的预算最关键的一点：一个 credit 是一次标准页面请求的成本，而“标准”取决于你抓取的网站。

根据 ScraperAPI 自己的定价文档，固定域名成本如下：

- 一个标准页面：**1 credit**
- Amazon 页面：**5 credits**
- Google 和 Bing（包括子域名）：**25 credits**
- LinkedIn：**30 credits**
- 受 Cloudflare、Datadome 或 PerimeterX 保护的网站：每当抓取工具绕过保护时，**每请求增加 10 credits**

参数会进一步累加。启用 `render=true`（用于 JS 密集型页面）会使成本增加约 10 credits。通过 `premium=true` 或 `ultra_premium=true` 路由到难以封禁的住宅池，根据目标不同，每次请求的成本为 10–30 credits。在对受保护的网站同时使用渲染和高级池，可能会使你的实际单页成本达到每 credit 名义价格的 20–30 倍。

具体来说：如果你在启用 JS 渲染的情况下抓取 Amazon 搜索结果页面，1,000,000 credits 的 Startup 计划可能只能覆盖 40,000–100,000 个实际页面。这仍然是一种可靠的容量 — 但这是一个与定价页上承诺的完全不同的数字。

有两个工具可以控制这一点。Dashboard 的 Domain Cost Estimator 可以显示你打算抓取的任何 URL 的确切 credit 成本，并且你可以在每次抓取时设置一个 `max_cost` 上限，这样意外的目标就不会耗尽你的计划额度。在提交付费计划之前，请在试用期间使用这两者：针对你的真实目标运行 Domain Cost Estimator，将结果乘以你的月量，只有这样，Hobby 和 Startup 之间的选择才有了真实的数字基础，而不是凭感觉。

**当 credits 用完时会发生什么取决于你的计划。** 默认情况下，抓取会暂停直到 credits 更新。Hobby 到 Professional 计划可以开启自动升级（opt-in），当 credits 用尽时，它会自动将你转入下一个计划。Scaling 及以上计划则改为获得按量付费（pay-as-you-go）选项：按固定的每 credit 费率继续抓取，直到你设置的每月上限。年度计划也可以提前续费以获得新的 credits 批次。

你会得到一个 429 响应并重试。没有罚款也没有额外费用；请求只是不会运行。

**试用期间或之后我可以使用住宅和移动 IP 吗？**
